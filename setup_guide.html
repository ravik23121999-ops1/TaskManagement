Welcome to QuickLifeNow! Follow this step-by-step guide to run both the Laravel API backend and React Vite frontend seamlessly on your local laptop from scratch.

1 Laptop Prerequisites

Before starting, verify you have the following standard development tools installed on your laptop:

Required Software Recommended Version Verification Command
PHP (with pdo_mysql, gd, fileinfo) 8.2, 8.3, or 8.4 php -v
Composer (PHP Package Manager) 2.5+ composer -V
Node.js & npm Node 18.x, 20.x, or 24.x node -v & npm -v
MySQL Server 8.0+ (or MariaDB / XAMPP) mysql --version
Git 2.30+ git --version
Tip for Windows Users: If using standalone PHP on Windows, make sure the following extensions are enabled in your php.ini file: extension=pdo_mysql, extension=fileinfo, extension=gd, extension=curl, extension=mbstring, extension=openssl.

2 Database Setup (MySQL)

Start your MySQL service (via Windows Services, XAMPP, or Terminal) and create the project database:

-- Log into MySQL in your command prompt:
mysql -u root -p

-- Run the SQL query to create the database:
CREATE DATABASE task_management CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- Confirm creation:
SHOW DATABASES;
EXIT;

3 Backend Setup (Laravel 12 API)

Open your command line (PowerShell or Terminal) and navigate to the project directory:

cd c:\Users\ADMIN\Desktop\TaskManagement\backend

Step 3.1: Environment Configuration

Ensure your .env file exists (copy from .env.example if creating a fresh clone):

copy .env.example .env

Confirm the database settings in backend/.env match your local MySQL configuration:

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=task_management
DB_USERNAME=root
DB_PASSWORD=your_mysql_password_here

APP_URL=http://127.0.0.1:8000
SANCTUM_STATEFUL_DOMAINS=localhost:5173

Step 3.2: Install Dependencies & Generate Application Key

composer install
php artisan key:generate

Step 3.3: Run Database Migrations & Initial Seed Data

This creates all required tables (users, departments, tasks, branches, reviews, work logs, avatars):

php artisan migrate --seed

Step 3.4: Create Public Storage Link (Crucial for Avatars & Files)

Connects backend/storage/app/public to backend/public/storage to prevent 403 download errors:

php artisan storage:link

Step 3.5: Start the Laravel API Server

php artisan serve --host=127.0.0.1 --port=8000

Your backend API is now running live at http://127.0.0.1:8000

4 Frontend Setup (React 19 + Vite)

Open a second, separate Terminal window (keep the Laravel server running in the first):

cd c:\Users\ADMIN\Desktop\TaskManagement\frontend

Step 4.1: Install Node Dependencies

npm install

Step 4.2: Start Vite Development Server

npm run dev
Ready! Open your web browser (Chrome, Edge, Firefox) and navigate to:
http://localhost:5173

7 Troubleshooting & FAQs

Q: MySQL Connection Refused (SQLSTATE[HY000] [2002])?

Solution: Ensure your MySQL service is running. On Windows, open services.msc, locate MySQL80 (or start Apache/MySQL in XAMPP), and click Start.

Q: Attachment or Avatar gives 403 Forbidden / Not Found?

Solution: Run php artisan storage:link in the backend/ folder. Confirm that backend/public/storage exists as a connected link.

Q: Port 8000 or 5173 is already in use?

Solution: You can start Laravel on another port: php artisan serve --port=8080 and Vite with npm run dev -- --port 3000.
