2. Task Creation, Routing & Allocation Flowchart

Demonstrates how tasks are configured, auto-dated on creation, routed through departments, and split into direct or multi-branch subtasks.

● Automatic Start Timestamp

Manual start date inputs have been eliminated. Tasks and subtasks automatically store start_date = now() on creation, preventing discrepancies.

● Dual Delegation Modes

Creators choose between Direct Delegation (one shared project deliverable) or Subtask Scopes (dedicated cards and private scopes per employee).

● Self-Assignment Prevention

FormRequest validation strictly blocks assigning a task to yourself under assign mode, directing users to work_alone for self-contained work.

3. Task Execution & Missing Details Loop Flowchart

Illustrates how team members request clarification, shift real-time responsibility, and how assigners provide missing assets without breaking project flow.

● Contextual Banners

When an employee asks a question, the top bar renders an amber alert "Missing Details Requested" with an instant [Provide Missing Details] modal for the assigner.

● Queue Handover Automation

The task moves out of the employee's active queue and into the assigner's "My Action Required", ensuring managers never lose track of questions blocking employees.

● Automatic Resolution State

Submitting clarification details automatically flips the task back to in_progress and marks the question answered, returning the ball to the assignee's court immediately.

4. Deliverable Submission, Review & Revision Return Loop

Details how submitted deliverables are evaluated, how returns for correction cleanly route feedback, and how resubmissions pass through quality gates.

● Clean Feedback Routing

When Admin rejects work with remarks (e.g. "make it right"), old questions are superseded. The employee receives a red banner with notes and a [Submit Fixes] action.

● Conflict-Free Dashboard

Admin dashboard displays "Returned for revision • Awaiting assignee" with zero false alerts, while the employee's screen clearly highlights "Action Required".

● Dual-Tier Sign-off Gate

Individual subtasks are approved first by their respective assigners. Once all sibling branches succeed, the Project Creator performs the final master sign-off.

5. Hierarchical Subtask Branching & Milestone Convergence

Illustrates multi-level organizational delegation down manager trees, peer privacy boundaries, and dynamic milestone progress aggregation.

● Multi-Tier Sub-Delegation

When enabled (can_assign_further = true), assignees can branch scopes down their organization tree. Sub-assignees report directly up their delegation hierarchy.

● Strict Peer Privacy Isolation

Assignees on Branch A cannot inspect private deliverables, files, or review comments on Branch B or C, ensuring confidential deliverables remain segregated.

● Automatic Milestone Aggregation

The master progress bar mathematically aggregates child branches: Progress = (Completed Branches / Total Branches) * 100, ensuring real-time executive reporting.

6. Administrative Governance, On-Hold & Cancellation Flowchart

Covers administrative oversight, pausing project SLA clocks with reasons, soft cancellation with audit trails, and deletion security gates.

● SLA Pause & Resume

Putting a task on hold requires documenting a clear rationale. All SLA timers pause and notification banners keep assignees informed until resumed.

● Traceable Soft Cancel

Cancelled tasks preserve all historical files, comments, and milestones with the exact timestamp and authorizing user recorded in the database.

● Deletion Authorization

Destructive deletions require Full Administrator clearance or an explicit system toggle (allow_subadmin_delete_records), preventing accidental data loss.

Security Architecture

7. Role-Based Access Control (RBAC) & Security Architecture

Details the 3-tier user authority matrix, API request security boundaries, peer privacy isolation, and compliance audit trail pipelines.

● 3-Tier Enterprise RBAC

Enforces clear separation of concerns between Admin (Executive Governance), Sub-Admin (Operational Oversight), and Employee (Focused Execution).

● Zero-Trust Peer Privacy

Employees assigned to collaborative tasks cannot inspect each other's private subtask descriptions, uploaded files, or reviewer feedback unless explicitly shared.

● Tamper-Proof Audit Trail

Every milestone transition, comment, review decision, and file attachment is permanently recorded in task_status_history with user attribution for regulatory compliance.
